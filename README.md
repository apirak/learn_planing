# Course Planner — algorithm จัดตารางเรียนให้น้อง

แนะนำคอร์สและลำดับการเรียนให้น้อง จากเป้าหมาย (คณะ/สถาบัน), เวลาที่เหลือ และความถนัดรายวิชา

## Flow

```
[1] เลือกเป้าหมาย ──> รู้วิชาที่ต้องสอบ + น้ำหนัก + วันสอบ
        │
[2] วันที่ปัจจุบัน ──> เวลาที่เหลือต่อวิชา ──> ตัด/ย่อคอร์ส (เช่น ตัดปรับพื้นฐาน)
        │
[3] ความถนัดรายวิชา ──> ถนัด: ข้ามไปทำโจทย์ / ไม่ถนัด: ปูพื้นฐานก่อน
        │
[4] ผลลัพธ์: รายการคอร์สที่ต้องลง + ลำดับ + ตารางเรียน
```

## Input

| ขั้น | ตัวแปร | ใช้ทำอะไร |
|---|---|---|
| 1 | คณะ + หลักสูตร | หาวิชาสอบและสัดส่วนคะแนน |
| 1 | สถาบัน (มหาวิทยาลัย) | ระบุหลักสูตรให้ชัด (รหัสหลักสูตร mytcas) |
| 2 | วันที่ปัจจุบัน | คำนวณเวลาที่เหลือก่อนวันสอบแต่ละวิชา |
| 2 | ความถนัดรายวิชา | เลือกจุดเริ่มเรียน (พื้นฐาน / โจทย์) |

## Output

- รายการคอร์สที่ต้องลง เรียงตามลำดับที่ควรเรียน
- เหตุผลต่อคอร์ส (น้ำหนักวิชา, เวลาที่เหลือ, ความถนัด)
- ตารางเรียนจนถึงวันสอบ

## ข้อมูลพื้นฐานที่ระบบต้องมี

1. **มหาวิทยาลัย** — รายชื่อ + หลักสูตรที่เปิด
2. **หลักสูตร** — รายชื่อทั้งหมด พร้อมรหัสหลักสูตร
3. **วิชาสอบต่อหลักสูตร** — วิชา + สัดส่วน % ที่ใช้คิดคะแนน
   ที่มา: <https://www.mytcas.com/blueprint/> (บางคณะมี TPAT1)
4. **ตารางสอบ** — วันสอบของแต่ละวิชา (TGAT/TPAT, A-Level)
5. **คอร์ส** — คอร์สของเรา map กับวิชาสอบ, ระดับ (พื้นฐาน / เนื้อหา / โจทย์), ชั่วโมงเรียน

### ตัวอย่างหลักสูตร

<https://course.mytcas.com/programs/10010121300001A>
คณะวิศวกรรมศาสตร์ / วิศวกรรมทั่วไป — วศ.บ. สาขาวิศวกรรมศาสตร์ (ภาษาไทย ปกติ) — จุฬาลงกรณ์มหาวิทยาลัย

| วิชาสอบ | สัดส่วน |
|---|---|
| TGAT ความถนัดทั่วไป | 20% |
| TPAT3 ความถนัดวิทยาศาสตร์ เทคโนโลยี วิศวกรรมศาสตร์ | 30% |
| A-Level คณิตศาสตร์ประยุกต์ 1 (พื้นฐาน+เพิ่มเติม) | 20% |
| A-Level ฟิสิกส์ | 20% |
| A-Level เคมี | 10% |

สัดส่วน % = น้ำหนักที่เอาคะแนนวิชานั้นมาคิด ใช้จัดลำดับความสำคัญของวิชา

## Algorithm (ร่าง)

```
subjects = exam_subjects(program)                 # จาก blueprint: [(วิชา, weight, exam_date)]
for s in subjects:
    days_left = s.exam_date - today
    level     = proficiency[s]                    # ต่ำ / กลาง / สูง
    track     = ["พื้นฐาน", "เนื้อหา", "โจทย์"]
    if level == สูง:   track = ["โจทย์"]
    if level == กลาง:  track = ["เนื้อหา", "โจทย์"]
    courses[s] = fit_to_time(track, days_left)    # ตัดจากต้น (พื้นฐาน) ก่อนถ้าเวลาไม่พอ
rank courses by s.weight desc                     # วิชาน้ำหนักมากได้เวลา/ความสำคัญก่อน
schedule(courses, today, exam_dates)              # กระจายชั่วโมงเรียนลงปฏิทิน
```

## Data model (ร่าง)

```
University { id, name }
Program    { id (mytcas code), university_id, faculty, name }
ExamReq    { program_id, subject_id, weight }
Subject    { id, name, exam_date }
Course     { id, subject_id, level: basic|content|practice, hours }
```

## ดึงข้อมูลจาก mytcas (TypeScript, Node ≥ 23.6)

```
pnpm install
pnpm scrape      # ดาวน์โหลดทั้งหมด → data/ (~10 วิ ถ้ามี cache data/raw/rounds/, ไม่มี ~2.5 นาที)
pnpm browse      # สร้าง browse.json ใหม่จากไฟล์ใน data/ ไม่ดึงเว็บ
pnpm t           # test (ไม่แตะเว็บ)
pnpm typecheck
```

```
src/main.ts      ลำดับขั้นทั้งหมด: download → build → บันทึกลง data/
src/download/    ดึงจากเว็บ 1 ไฟล์ต่อแหล่ง (programs, universities, admission-rounds, exam-subjects, score-keys)
src/parse/       แปลง HTML/JS ของเว็บเป็นข้อมูล — ใช้ใน download/
src/build/       เอาสิ่งที่ดาวน์โหลดมารวมเป็นไฟล์ที่ใช้งาน (program-exams, browse, ...) — ไม่แตะเว็บ
src/shared/      fetch + retry, อ่าน/เขียน data/, types ของทุกไฟล์
test/            โครงเดียวกับ src/
```

## data/browse.json (ข้อมูลของ ui/)

สร้างใหม่โดยไม่ดึงเว็บ: `pnpm browse` · `fetched_at` = เวลาที่ดึง programs.json · `count` = จำนวนหลักสูตร

```
data.groups        { "30": "วิศวกรรมศาสตร์" }               กลุ่มสาขา (ใช้เป็น "คณะ") 15 กลุ่ม
data.fields        { "30-05": "วิศวกรรมคอมพิวเตอร์" }       key = group-field (ชื่อซ้ำข้ามกลุ่มได้)
data.universities  { "001": "จุฬาลงกรณ์มหาวิทยาลัย" }
data.subjects      { "tgat1": "การสื่อสารภาษาอังกฤษ (TGAT1)" } เฉพาะวิชาที่มีหลักสูตรใช้
data.programs      [{ id, name, type, uni, group, field, exams: { subject: weight } }]  1 แถวต่อ program_id
```

ความหมายของ `exams` (รวมทุกรอบรับ ยังไม่มีรอบ 4):

- มี key = วิชาอยู่ในสัดส่วนคะแนน หรือคะแนนขั้นต่ำ ของรอบใดรอบหนึ่ง · `{}` = ยังไม่มีข้อมูลคะแนนสอบ: รับแค่ portfolio / เกรด หรือรอบที่ใช้คะแนนยังไม่อยู่ใน mytcas (เช่น แพทย์/ทันตะ ยังไม่มีรอบ 3 กสพท) — แยกสองกรณีนี้ไม่ได้
- `weight` = % สูงสุดในทุกรอบ · `0` = ใช้แค่คะแนนขั้นต่ำ ไม่มีสัดส่วน
- key รวมถูกแตกเป็นวิชา: `tgat` 20% → tgat1/2/3 ขึ้น 20 ทุกตัว (= น้ำหนักของ TGAT ทั้งก้อน ไม่ใช่ต่อวิชา)
- ผลรวมหลายวิชา (`cal_*` เช่น a_lv_61+a_lv_64+a_lv_82 = 100%) แบ่งน้ำหนักเท่า ๆ กัน → 33 ต่อวิชา
